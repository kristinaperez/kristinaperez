# 👋 Привет! Я разработчик Telegram Mini Apps с бэкендом, выполняю интеграцию ChatGPT/Claude, 
		        устанавливаю защиту от DDoS и SQL/NOSQL инъекций

Строю **HTML5-игры**, **Telegram Mini Apps** и **ботов для обратной связи**. Уделяю особое внимание чистому коду на Vanilla JS, высокой производительности и гладкому UX/UI.
